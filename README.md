## 🚀 Featured Projects

### 🌍 TerraQuest
`Java 21` · `Spring Boot 3` · `PostgreSQL + PostGIS` · `Redis` · `React` · `MapLibre`

A free, open-source geography guessing game. Panorama-first imagery harvesting, country-quota sampling so the game doesn't just show you Kansas forever, Redis-backed sessions, and a PostGIS scoring pipeline that turns a click on a map into a distance-based score.

### ⚡ Distributed Task Queue Engine
`Java` · `Spring Boot` · `PostgreSQL` · `Docker`

A job-processing backend where multiple workers pull from one queue without ever stepping on each other. Built on PostgreSQL's `SELECT … FOR UPDATE SKIP LOCKED` for lock-free claiming, with a thread-pooled worker model, retry semantics, and durable state — so a job is never silently processed twice.

### 🤖 AI Codebase Assistant
`Java` · `Spring Boot` · `Python` · `FastAPI` · `ChromaDB`

Ask a large repository questions in plain English. Indexes code with semantic embeddings and answers via RAG, on a dual-backend design: a Spring Boot API orchestrates a Python microservice that owns embeddings and vector search.

### 🛣️ Real-Time Lane Detection
`C++` · `OpenCV` · `React` · `TypeScript`

A computer-vision pipeline that tracks road lane markings from video using polynomial curve fitting — handling the curved roads that naive Hough-line detection quietly gives up on.

### 📈 Queue Prediction REST API
`C++` · `cpp-httplib`

An M/M/1 queuing-theory simulator served over HTTP, predicting wait times and queue lengths from arrival and service rates. Queuing theory, but with a `curl` interface.
